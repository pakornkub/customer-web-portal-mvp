# Design Docs

This folder contains the visual direction for the next project.

## Contents

- `DESIGN.md` shared design system and token guidance
- `ORDER-SCREEN-PROMPT.md` order-page specific prompt derived from the reference
  screenshots
- screenshot assets used as style references

## Usage

- Start with `DESIGN.md` for baseline colors, typography, spacing, and component
  behavior.
- Use `ORDER-SCREEN-PROMPT.md` when prompting AI to build the Orders page or
  related workflow screens.
- Treat the screenshots as style references, not exact HTML replication targets.
