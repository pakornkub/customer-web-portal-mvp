# Instruction Docs

This folder contains AI-facing implementation instructions.

## Contents

- `copilot-instructions.md` broader coding conventions for the target Next.js
  project
- `workflow-skill.instructions.md` focused workflow/order skill guidance

## Usage

- Read `copilot-instructions.md` after the requirements are understood.
- Read `workflow-skill.instructions.md` only for the unified Orders workflow and
  permission work.
- Do not use this folder as the primary source of business requirements; start
  from the root `README.md` and the `requirements/` folder first.
